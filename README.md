# 💻 Portfólio | Bernardo Quintas Lino

Bem-vindo ao repositório do meu portfólio profissional! Este projeto foi desenvolvido para apresentar as minhas competências, serviços e os sistemas web que criei.

## 👨‍💻 Sobre Mim
Sou **Engenheiro Informático** com mais de 3 anos de experiência no desenvolvimento de sistemas web, gestão de dados e soluções digitais para empresas e instituições em Angola. O meu foco é transformar processos manuais em plataformas digitais simples, rápidas e seguras.

## 🚀 Tecnologias Utilizadas neste Portfólio
Este site foi construído do zero, sem frameworks pesadas, focando na performance e no design moderno:
*   **HTML5** (Estrutura semântica)
*   **CSS3** (Design responsivo, variáveis, animações e Dark Mode)
*   **JavaScript** (Interatividade e navegação suave)
*   **Font Awesome** (Ícones)
*   **Google Fonts** (Tipografia Inter)

## 📁 Estrutura do Projeto
*   `index.html` - Página inicial (Hero e Projetos em Destaque)
*   `sobre.html` - A minha biografia, competências e percurso.
*   `servicos.html` - Detalhes dos serviços que ofereço.
*   `projetos.html` - Lista completa dos meus trabalhos.
*   `contacto.html` - Página de contactos e localização.
*   `detalhes-*.html` - Páginas de estudo de caso (Case Studies) de cada projeto.
*   `style.css` - Folha de estilos global.
*   `img/` - Todas as imagens e recursos visuais.
